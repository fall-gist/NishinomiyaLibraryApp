# NishinomiyaLibraryApp

西宮市立図書館 家族用Androidアプリ(非公式・非公開)

家族全員分の「借りている本・返却期限・予約状況・マイ本棚」を1つのアプリに集約し、
返し忘れ・受取忘れをなくすためのアプリ。

## APKのインストール・更新

CIの `assembleDebug` が生成する `app-debug.apk` を家族端末に直接インストールする。

- **署名は固定のdebug鍵**(`app/debug.keystore`)。全ビルドで同じ鍵を使うため、
  以降はアンインストールせずに**上書き更新**できる。
- この固定鍵を導入する**前にインストールした版がある場合は、初回だけ**古い署名と
  食い違うため一度アンインストールしてから入れ直す(以降の更新は上書きでよい)。
- 初回インストール時に Google Play プロテクトが「未スキャン」警告を出すことがある。
  `詳細 ▾` →「インストールする」で続行できる。
- debug鍵は秘匿情報ではない(パスワードは慣例の `android`)。リリース用の鍵を使う場合は
  リポジトリに含めず GitHub Secret 等で管理すること。

## 注意

- 本アプリは非公式です。西宮市および西宮市立図書館とは関係ありません
- 図書館サイトへは読み取りアクセスのみ。認証情報はリポジトリに含めないこと
