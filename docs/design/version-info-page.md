# バージョン情報ページ 設計書（案）

作成日: 2026-09-27
状態: **文面案の検討中（所有者へ提示）**。実装は文面の確定後
依頼: 所有者（2026-09-27）「アプリ内でバージョン情報を確認できるページを設けたい。ページトップには
バージョン番号を記載し、下部にはバージョンごとの更新履歴・内容を記載する。まずは1.0〜1.10までの内容を
記載した案までを検討して」

## 1. 画面の構成（案）

### 1.1 入口

設定画面の最下部に「バージョン情報」の行を置き、タップで開く。
診断ログ（設定画面から開く全画面の表示。`LibraryApp` の `diagnosticLogOpen`）と同じ形の全画面表示にする。
戻るキーと画面上部の「←」で閉じる。

### 1.2 上部

```
西宮市立図書館アプリ
Ver.1.10
ビルド 512（abc1234）            ← 小さく、薄い色で
```

- 大きく出すのは `versionName`（`BuildConfig.VERSION_NAME`）
- その下に小さく、ビルド番号（`versionCode`。コミット数から自動付与）とコミットの識別子
  （`BuildConfig.GIT_SHA` の先頭7文字）を出す。**同じ版番号のまま修正版を試していただくときに、
  どのビルドかを見分けるため**（2026-09-26 の切り分けで困った件への対処を兼ねる）

### 1.3 下部: 更新履歴

- 新しい版を上に並べる
- 1つの版ごとに「版番号・日付・見出し1行・箇条書き」
- 文面は利用者向けとし、内部の用語（コントローラ名、lost update など）は使わない
- 不具合の修正は「〜するようにしました」「〜を直しました」の形で、何が変わったかを書く

### 1.4 文面の置き場所

更新履歴の文面はアプリのコードの中に持つ（純粋な Kotlin のデータとして1か所にまとめる）。
通信で取りに行かない。開発者向けの記録（`docs/design/release-build.md` の履歴表）とは別物として扱い、
版を上げるときに両方を更新する。

## 2. 更新履歴の文面（案。1.0〜1.10）

日付は versionName を上げた日（1.0 は所有者の決定どおりリリース版とした 2026-08-06）。

---

### Ver.1.10（2026-09-27）
**処理中でも書誌詳細がすぐ開くようになりました**
- 一斉予約などの処理中に、書誌詳細・検索・新着資料の読み込みが待たされないようにしました

### Ver.1.9（2026-09-26）
**本棚が1つもないときの操作を直しました**
- 本棚を1つも持っていない人が、本棚を作成できなかった不具合を直しました
- 最後の1つの本棚を削除すると「結果を確認できません」と表示され、その後その人の本棚を操作できなくなる不具合を直しました
- 処理中の表示（画面下の帯）を緑色にして、見やすくしました

### Ver.1.8（2026-09-26）
**処理中も画面を移れるようになりました**
- 一斉操作や同期の進み具合を、画面下の帯に表示するようにしました。処理中も他の画面へ移れます
- 処理が終わると、帯でお知らせします（数秒で消えます。タップでも消せます）
- 本棚への一斉追加で、終わるまで操作できなかった表示をなくしました

### Ver.1.7（2026-09-26）
**複数選択を長押しで始めるようにしました**
- 貸出中・予約中・蔵書検索・新着資料・読書記録で、本を長押しすると複数選択を始められるようにしました。選択中は、タップで選択を切り替えます
- 読書記録から、複数の本をまとめて予約・カートへ追加・本棚へ追加できるようにしました
- 読書記録の検索で、空白で区切った複数の言葉をすべて含む本を探せるようにしました
- 蔵書検索で別の言葉を検索したときや、他の画面へ移ったときに、前の検索の選択やメッセージが残らないようにしました
- 予約中・予約カートから開いた書誌詳細で、文字を長押しするとアプリが終了する不具合を直しました

### Ver.1.6（2026-09-20）
**まとめて操作できることが増えました**
- 貸出中の本をまとめて延長できるようにしました
- 予約カートから複数の本をまとめて削除できるようにしました。カートを空にすることもできます
- 蔵書検索・新着資料から、複数の本をまとめてカートへ追加・予約・本棚へ追加できるようにしました
- 選んだ本が解除される前に確認を出すようにしました（設定で出さないようにもできます）

### Ver.1.5（2026-08-29）
**返却のお知らせの文言を直しました**
- 返却日の当日や期限を過ぎた本についても「明日返却の本があります」とお知らせしていた不具合を直しました。状況に合わせて「今日が返却期限」「返却期限が過ぎた」などと表示します

### Ver.1.4（2026-08-21）
**カレンダーに返却期限を表示するようにしました**
- 開館カレンダーの日付に、その日が返却期限の本があることを家族の色の点で表示するようにしました
- 日付をタップすると、貸出中の画面でその日が期限の本を表示します

### Ver.1.3（2026-08-18）
**設定の書き出し・読み込みを仕上げました**
- 書き出したファイルに、パスワードを暗号化して含めるようにしました
- 家族を登録する前の最初の画面から、書き出したファイルを読み込んで復元できるようにしました

### Ver.1.2（2026-08-17）
**予約と本棚の不具合を直しました**
- メールアドレスを登録していない場合に、予約ができなかった不具合を直しました
- 本棚の変更で、操作したものとは別の本棚が消えてしまう不具合を直しました
- 本棚を1つも持っていない人がいると、同期が止まる不具合を直しました
- 設定を書き出し・読み込みできるようにしました（機種変更などに使えます）

### Ver.1.1（2026-08-09）
**マイ本棚を編集できるようにしました**
- 本棚の作成・削除、本の追加・削除、本棚の名前やメモの変更ができるようにしました
- お知らせをタップするとアプリが開くようにしました

### Ver.1.0（2026-08-06）
**最初の版**
- 家族全員の貸出中・予約中・読書記録・マイ本棚をまとめて確認できます
- 蔵書検索・新着資料・開館カレンダーを見られます
- 本を予約・予約の取消・貸出の延長ができます。予約カートにためてまとめて予約することもできます
- 新着資料から、登録した条件に合う本を自動で予約できます
- 返却期限が近い本や、受け取れる予約をお知らせします

## 3. 所有者へ確認したいこと

1. 文面の粒度と言葉づかい（上の案でよいか、もっと短くするか）
2. 1.0 の内容の書き方（機能の一覧として書いたが、単に「最初の版」だけにするか）
3. 上部のビルド番号・コミットの識別子を出すか（切り分け用。不要なら版番号だけにする）
4. 入口の位置（設定画面の最下部でよいか）

## 4. 実装（文面の確定後に設計を詰める）

- 更新履歴の文面を Kotlin のデータとして1か所に置く。版番号の並びと `BuildConfig.VERSION_NAME` の
  先頭が一致することを単体テストで固定する（版を上げたのに履歴を書き忘れる、を防ぐ）
- 画面は設定画面から開く全画面表示
