# にしのみや図書館 家族用アプリ 仕様書

最終更新: 2026-07-17(仕様確定)

## 1. コンセプト

西宮市立図書館を使う**家族のための非公開Androidアプリ**。
家族全員分の「借りている本・返却期限・予約の状況・マイ本棚」を1つのアプリに集約し、
返し忘れ・受取忘れをなくす。

- ストア公開はしない(家族の端末に直接インストール)
- 図書館公式サイト(LICS-XP)への**読み取りアクセスのみ**。予約・延長など
  サイトの状態を変える操作は行わない(将来の拡張余地としては設計で考慮する)

## 2. アカウント

- 家族**5人分**の利用者アカウントを登録できる(人数は拡張可能な設計とする)
- 各アカウント: 表示名 / 識別色 / 図書館カード番号 / パスワード
- 認証情報は**端末内に暗号化保存**(Android Keystore)。外部送信・リポジトリ格納は厳禁

## 3. 機能仕様

### 3.1 ホーム(家族統合ビュー)

- 家族**全員分を統合**したダッシュボード。メンバーは名前+識別色で区別
- 表示内容:
  - 返却期限が近い本(期限順、期限超過は強調)
  - 受取可能になった予約
  - 最終同期時刻
- メンバーによる絞り込みフィルタ

### 3.2 蔵書検索

- キーワード検索(かんたん検索相当)。オートコンプリート候補表示(公式JSON API)
- 検索結果: タイトル / 著者 / 出版社 / 貸出可否○×(公式JSON API `getIsLend`)
- 書誌詳細: 書誌事項+所蔵一覧(館 / 請求記号 / 配架場所 / 在庫状態)
- 予約ボタンは**置かない**(読み取り専用)

### 3.3 利用状況(メンバー別詳細)

- 貸出中一覧: 資料名 / 貸出館 / 貸出日 / 返却期限日
- 予約中一覧: 資料名 / 受取館 / 予約順位 / 予約状態 / 取置期限

### 3.4 マイ本棚(参照)

- 公式サイトの「マイ本棚」を読み取り専用で表示(資料名 / メモ / 登録日)
- 書誌詳細への導線あり

### 3.5 開館カレンダー

- **一度に一館のみ表示**(ごちゃつき防止)。表示館はドロップダウン等で選択
- 対象: 全12施設(中央 / 北口 / 鳴尾 / 北部 / 越木岩 / 若竹 / 段上 / 上ケ原 / 甲東園 / 高須 / 山口 / 義務教育校)
- 既定表示館を設定できる
- 休館日をカレンダー形式で表示(公式サイトから約3ヶ月分取得)

### 3.6 通知

| 通知 | タイミング | 形式 |
|---|---|---|
| 返却期限リマインダー | 期限**前日** | 家族**まとめて1通**(例:「明日返却: パパ3冊・長女2冊」) |
| 予約受取可能 | 同期時に受取可を検知したら | まとめて1通 |

- 順位上昇などその他の通知は**行わない**
- **通知のオン/オフ設定は必須**(種類ごとに切替可能)

### 3.7 同期

- 自動同期: **毎日18時に1回**(閉館後を想定)。**時刻は設定で変更可能**
- 手動同期: プルリフレッシュ
- 取得結果はローカルDB(Room)にキャッシュし、オフラインでも最終取得状態を表示

### 3.8 表紙画像

- openBD等の公開APIからISBNで**都度取得**
- **メモリキャッシュのみ**(アプリ終了で消える)。**ディスクキャッシュは持たない**
  (ストレージ消費を避けるため)
- 非同期・遅延ロードで、画像待ちがUI操作をブロックしないこと

## 4. 非機能要件

- **サイト負荷への配慮**: 自動同期は1日1回。手動更新も連打を抑制(クールダウン)
- **パーサの分離**: スクレイピング部分は独立モジュールとし、サイト改修時に
  差し替えやすくする。パース失敗はアプリ内で検知・表示する
- **拡張性**: 予約実行・延長などの書き込み操作を将来追加できるよう、
  通信クライアントはメソッド追加で拡張できる構造とする
- 対応OS: Android 8.0 (API 26) 以上

## 5. 実装しないこと(確定)

- 予約・延長・登録変更などサイトへの書き込み操作(今回スコープ外)
- ISBNバーコードスキャン(不要と判断)
- 予約順位の上昇通知
- 表紙画像のディスクキャッシュ
- ストア公開・多言語対応
