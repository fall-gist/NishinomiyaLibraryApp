比較

案1冊あたり高さ分かること向き / 弱み
現状大(可変)書名・館・人・期限すべて1画面性が最も低い。長い書名で破綻
1-1小・固定いつまでに / どこで / 誰 / 何冊「期限が近い順」が主眼のときに最良。館は期限内で分散
1-2最小・固定どこで / 誰 / 何冊受取の外出計画に最短。ただし期限の緊急度は別画面頼み
2小・固定(1行)書名(要約) / 館 / 期限「どの本か」を残しつつ圧縮。館名は略称になる

補足: いずれの案も、行/グループをタップで予約画面へ遷移して詳細確認できる前提。取置期限の「未定」は、公式サイトで受取館が割当前(全館名が並ぶ状態)のもの。案1-1と案2は期限を色(赤)で強調でき、案1-2は最終同期時刻に依存せず「今どこに何冊あるか」だけを見せる割り切り。
